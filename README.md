# 💌 Convite para um Date

Site interativo de convite, em 5 etapas:

1. **Envelope lacrado** — ela rompe o lacre dourado
2. **A carta** — "Aceitas um date?", com o botão "Não" que foge
3. **Raspadinha** — revela dia, hora e local
4. **E depois do jantar…** — ela escolhe as opções picantes para o pós-date
5. **Reserva confirmada** — ingresso com contagem regressiva, agenda e resposta por WhatsApp (com as escolhas dela)

## Como personalizar
Abra `index.html` e edite o bloco `CONFIG` no início do `<script>` (nomes, pergunta, data, local, dress code, WhatsApp e a lista `depois`).

## Como publicar (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → `main` / `root`. O link fica `https://<usuario>.github.io/<repo>/`.
