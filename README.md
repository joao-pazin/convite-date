# 💌 Convite para um Date

Site interativo de convite, em 5 etapas:

1. **Carta lacrada** — toque no lacre de cera para abrir o envelope
2. **Carta datilografada** — a mensagem vai sendo escrita na hora
3. **A pergunta** — o botão "Não" foge e muda de texto até virar "Sim"
4. **Raspadinha** — raspe o cartão dourado para descobrir dia, hora e local
5. **Ingresso VIP** — com contagem regressiva, botão para salvar na agenda e confirmar pelo WhatsApp

## Como personalizar
Abra `index.html` e edite o bloco `CONFIG` no início do `<script>` (nomes, carta, data, local, dress code, WhatsApp).

## Como publicar (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → `main` / `root`. O link fica `https://<usuario>.github.io/<repo>/`.
